# concerts

A personal live-music archive: upcoming shows and past ones, with ratings and notes.

## Adding a show

Every show lives in [`contents/concerts.yml`](contents/concerts.yml). Add an entry there and commit; the page picks it up automatically. Shows dated today or later appear under **Coming up**, earlier ones become **Reviews**. The comment at the top of that file lists every field.

## Hosting

Served with GitHub Pages from the `main` branch (Settings → Pages → Deploy from a branch → `main` / root).
